=> 1.4.0

# New features

Added two context keys, which enables selectively defining keybinds
- "mise.upglob_has_keyfile": evaluates to true when the open file has a keyfile in any parent directory.
- "mise.project_has_keyfile": evaluates to true when the open project has a keyfile in any of its configured folders (top-level only).

(Note: supported keyfiles are currently mise.toml or mise.local.toml)

This allows, for example, overriding default keybinds like follows, to use the Mise task picker over
build systems only when the open project uses Mise.

```
{
	"keys": [
		"ctrl+shift+b"
	],
	"command": "show_overlay",
	"args": {
		"overlay": "command_palette",
		"command": "mise_run_task"
	},
	"context": [
		{
			"key": "mise.project_has_keyfile",
			"operand": true,
			"operator": "equal"
		}
	]
}
```

References:
https://www.sublimetext.com/docs/key_bindings.html#context-key
